# نیازمندی‌های فنی اتصال پلتفرم به بازار استودیو

**مخاطب:** امیر شریف‌زاده و بهروز
**پلتفرم:** میدان بنیان‌گذاران (festival.pegah.tech)
**وضعیت:** پیش‌نویس برای بررسی. پلتفرم بدون این اتصال هم کار می‌کند، چون تا آماده‌شدن API، ادمین آمار را دستی یا با اکسل وارد می‌کند.

## خلاصه

تیم‌های مسابقه محصولشان را روی بازار منتشر می‌کنند و ۳۰٪ امتیاز نهایی محور عمومی از بخش بازار می‌آید. از این ۳۰٪، یک‌پنجم حمایت با سکه داخل پلتفرم است و بقیه از آمار واقعی بازار. از شما دو چیز لازم داریم:

1. **API خواندن آمار** هر محصول (ضروری).
2. **API یا فرایند ثبت درخواست انتشار** (اختیاری؛ فرایند فعلی هم قابل ادامه است).

یک پرسش هم باز است که باید شما جواب بدهید: [حساب مشترک گروه](#پرسش‌های-باز).

## فرایند فعلی انتشار

1. تیم محصول را در پلتفرم ثبت نهایی می‌کند.
2. تیم درخواست انتشار می‌دهد: لینک سورس، توضیح و شناسهٔ بسته.
3. تیم بازار استودیو درخواست را در پلتفرم می‌بیند، بررسی می‌کند و منتشر می‌کند. برای این کار نقش «اپراتور بازار استودیو» در پلتفرم هست که فقط به درخواست‌های انتشار و آمار دسترسی دارد.
4. پس از انتشار، آمار از زمان انتشار تا مهلت نهایی مسابقه در امتیاز حساب می‌شود و در مهلت نهایی یک برداشت قطعی گرفته می‌شود.

## API خواندن آمار

### شناسایی محصول

پلتفرم هر محصول را با **شناسهٔ بسته (package name)** می‌شناسد و تیم آن را هنگام درخواست انتشار وارد می‌کند. اگر بازار شناسهٔ دیگری دارد، لازم است بدانیم.

### شاخص‌های لازم

| شاخص | توضیح | سهم پیش‌فرض از بخش بازار |
| --- | --- | --- |
| نصب فعال | نصب‌های فعال فعلی، نه کل نصب‌ها | ۳۳٪ |
| درآمد واقعی | به تومان، از ابتدای انتشار | ۲۴٪ |
| امتیاز ستاره‌ای | میانگین ۰ تا ۵ | ۱۴٪ |
| تعداد نظر | تعداد کل نظرها | ۹٪ |

سهم باقی‌مانده (۲۰٪) حمایت با سکه داخل پلتفرم است. این درصدها در پنل ادمین قابل تغییرند.

### شکل پیشنهادی پاسخ

این فقط پیشنهاد است و هر قالبی که برایتان راحت‌تر است قابل قبول است.

```http
GET /v1/apps/{packageName}/metrics
Authorization: Bearer <token>
```

```json
{
  "packageName": "ir.example.app",
  "activeInstalls": 1240,
  "revenueToman": 3500000,
  "rating": 4.3,
  "commentCount": 57,
  "updatedAt": "2026-11-10T08:00:00Z"
}
```

اگر بسته را نشناسید، پاسخ `404` کافی است. پلتفرم آن محصول را رد می‌کند و بقیه را ادامه می‌دهد.

### نیازهای غیرعملکردی

- **احراز هویت:** یک توکن سرور به سرور فقط‌خواندنی کافی است. پلتفرم توکن را در متغیر محیطی نگه می‌دارد.
- **دسترسی شبکه:** سرور پلتفرم باید به API دسترسی داشته باشد. اگر API داخلی است، نشانی و نیاز به VPN یا لیست سفید IP را مشخص کنید.
- **بازهٔ به‌روزرسانی:** برای لیدربورد زنده، به‌روزرسانی ساعتی کافی است و روزانه هم قابل قبول است. پلتفرم هر بسته را جدا می‌خواند؛ اگر endpoint گروهی راحت‌تر است، بگویید.
- **محدودیت نرخ:** سقف درخواست را اعلام کنید. تعداد محصولات مسابقه در حد چند ده است.
- **برداشت نهایی:** در مهلت نهایی، آمار قفل می‌شود. لازم است API در آن لحظه در دسترس باشد؛ یا بتوانیم آمار یک تاریخ مشخص را بعداً بخوانیم که بهتر است.

### جداکردن نصب‌های معتبر

اگر بازار نصب معتبر را از نصب مشکوک جدا می‌کند، `activeInstalls` باید فقط نصب‌های معتبر باشد. اگر سیگنال تقلب هم دارید (مثلاً یک پرچم مشکوک)، آن را اضافه کنید: پلتفرم محصول پرچم‌خورده را برای بررسی به داور و ادمین می‌فرستد و آمارش تا رفع پرچم در امتیاز حساب نمی‌شود. این پرچم الان دستی است.

## ثبت درخواست انتشار (اختیاری)

الان درخواست داخل پلتفرم می‌ماند و تیم شما از همان‌جا آن را می‌بیند. اگر ترجیح می‌دهید درخواست‌ها مستقیم به سیستم شما برود، یک endpoint برای دریافت درخواست و یک callback یا endpoint برای برگرداندن وضعیت (در حال بررسی، نیاز به اصلاح، منتشرشده) لازم است. این بخش جلوی شروع مسابقه را نمی‌گیرد.

## پرسش‌های باز

1. **حساب انتشار:** فعلاً فرض شده هر تیم با حساب خودش در بازار منتشر می‌کند. آیا انتشار زیر یک حساب مشترک گروه ممکن است؟ اگر بله، درآمد و آمار هر محصول چطور جدا می‌شود؟
2. **درآمد:** برای محصولاتی که پرداخت درون‌برنامه‌ای ندارند، درآمد صفر حساب می‌شود. آیا منبع درآمد دیگری هم باید در نظر گرفته شود؟
3. **آمار تاریخی:** می‌توان آمار یک تاریخ گذشته را خواند؟ این برای برداشت نهایی و بررسی اختلاف مهم است.
4. **زمان آماده‌شدن:** چه زمانی API آماده می‌شود؟ مسابقه سه هفته است و تا آن زمان ورود دستی ادامه دارد.

## سمت پلتفرم چه آماده است

- محل اتصال: `src/lib/bazaar.ts`. فقط باید یک پیاده‌سازی از `BazaarDriver` نوشته شود (`fetchMetrics(packageName)`) و بقیهٔ کد تغییر نمی‌کند.
- منبع آمار در پنل کنترل ادمین انتخاب می‌شود: دستی، API یا خاموش.
- ورود دستی و اکسل، پرچم مشکوک، همگام‌سازی زمان‌بندی‌شده در پس‌زمینه و برداشت نهایی از قبل ساخته شده‌اند.
- برای محورهایی که روی بازار منتشر نمی‌شوند (تولید محتوا و راهکار OS)، وزن آمار بازار بین هوش مصنوعی و داوری پخش شده است و به API نیازی ندارند.
